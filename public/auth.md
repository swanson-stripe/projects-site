# Authentication

The public `projects.dev` site does not currently require OAuth, OpenID Connect, or agent registration for its public discovery resources.

## Public resources

- `/.well-known/api-catalog`
- `/docs/api/`
- `/api/openapi.json`
- `/api/health`
- `/llms.txt`
- `/skill.md`

## Auth status

- Authentication required: No
- Agent registration required: No
- OAuth/OIDC discovery: Not published because the public site does not expose protected API resources today
