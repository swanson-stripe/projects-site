# Stripe Projects

> Stripe Projects is a CLI tool that scaffolds production-ready, full-stack applications with Stripe payments, authentication, a database, and deployment pre-configured. Run one command and get a working app — no boilerplate required.

**Website:** https://stripe.com/projects  
**Documentation:** https://stripe.com/docs  
**GitHub:** https://github.com/stripe

---

## What is Stripe Projects?

Stripe Projects is a developer tool that eliminates the hours spent connecting payment infrastructure, configuring authentication, choosing a database, and setting up deployment pipelines. Every new application generated by Projects starts with Stripe fully integrated and immediately capable of accepting real payments.

The tool is designed for developers who want to ship products, not configure infrastructure. It generates a complete, working full-stack application tailored to the developer's preferred tech stack.

---

## Getting Started

Install and scaffold a new application with a single command:

```bash
stripe projects create my-app
```

Initialize services and configuration:

```bash
stripe projects init
```

Add an ecosystem service to your project:

```bash
stripe projects service add <service-name>
```

## Features

### From Local to Live in One Command
Go from local development to a running production stack in minutes. One command provisions everything your app needs across providers.

### Automated Secure Credentials
Receive real credentials directly to a secret store—no copying keys across tabs. Agent-readable and auditable by default.

### No Vendor Lock-In
Keep full ownership of every account. Services are provisioned directly in your provider accounts—with the freedom to leave anytime.

### Deploy with Confidence
Provision the same environment every time. Centralized billing and real-time usage visibility across providers means no surprises.

## Ecosystem — Supported Services

Projects integrates with leading services across every category needed to build a modern application. Services are added via `projects service add <name>`.

### Payments
- **Stripe** — Accept one-time payments, subscriptions, and invoices. Pre-wired with no boilerplate. https://stripe.com

### Authentication
- **Clerk** — Drop-in authentication with social login, magic links, MFA, and full user management UI. Works out of the box with zero configuration. https://clerk.dev

### Database
- **Neon** — Serverless Postgres with autoscaling to zero, database branching, and a generous free tier. Spin up a new branch for every PR automatically. https://neon.tech
- **PlanetScale** — MySQL-compatible serverless database with non-blocking schema changes, automatic sharding, and branching workflows. https://planetscale.com

### Storage
- **Supabase** — Open-source Firebase alternative with Postgres, realtime subscriptions, file storage, and auto-generated APIs. Fully managed and infinitely scalable. https://supabase.com

### Hosting & Deployment
- **Vercel** — Deploy frontend apps to the edge with automatic CI/CD, edge functions, and global CDN distribution. Seamless integration with Next.js and all major frameworks. https://vercel.com
- **Railway** — Deploy servers, databases, and cron jobs with zero ops overhead. Railway handles provisioning, networking, and scaling. https://railway.app

### Analytics
- **PostHog** — Self-hostable product analytics with event capture, session replay, feature flags, and A/B testing. Everything you need to understand and improve your product. https://posthog.com

### Monitoring
- **Sentry** — Full-stack error monitoring, performance tracing, and alerting. Pre-configured with zero setup required. Catch errors before your users do. https://sentry.io

### AI / Vector Database
- **Chroma** — Open-source embedding database for AI applications. Store, search, and manage vector embeddings at any scale with a simple Python and JavaScript API. https://trychroma.com

### Edge & Background Jobs
- **Cloudflare** — Global edge network with Workers, Pages, R2 storage, D1 database, and built-in DDoS protection. Deploy compute at the edge in 300+ cities with zero cold starts. https://cloudflare.com
- **Inngest** — Write reliable background jobs, scheduled tasks, and multi-step workflows as plain TypeScript functions. Automatic retries, observability, and concurrency control with zero infrastructure. https://inngest.com

### Email & Communications
- **SendGrid** — Send transactional emails — verification, receipts, password resets — through a battle-tested API trusted by over 80,000 businesses. Pre-wired with ready-to-use templates and delivery analytics. https://sendgrid.com
- **Twilio** — Add SMS notifications, voice calls, and two-factor authentication to your app with a single unified API. Reach users on any channel — phone, WhatsApp, or email — from day one. https://twilio.com

### AI / Voice & Model Routing
- **ElevenLabs** — Generate human-quality speech in 32 languages with ultra-low latency. Clone voices, build interactive voice agents, and stream audio in real time through a simple REST API. https://elevenlabs.io
- **OpenRouter** — Access 200+ AI models — GPT-4, Claude, Gemini, Llama, and more — through a single OpenAI-compatible API. Automatic fallbacks, cost optimization, and usage analytics built in. https://openrouter.ai

## CLI Reference

| Command | Description |
|---------|-------------|
| `stripe projects create <app-name>` | Scaffold a new full-stack application |
| `stripe projects init` | Initialize services and configuration |
| `stripe projects service add <name>` | Add an ecosystem service |
| `stripe projects service list` | List available services |
| `/contest` | Submit contest entry from within the CLI |
| `/install` | Show install command |
| `/services` | Show available services list |
| `/help` | Show available commands |
